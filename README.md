# Poseidon Service Website

Static bilingual marketing site for Poseidon Service Kft., rebuilt from the scraped source material as an Astro project for Cloudflare Pages deployment.

## Site Summary

- Hungarian default homepage at `/`
- English secondary homepage at `/en/`
- Sections for about, services, pricing, references, and contact
- Local image gallery sourced from the scraped assets
- Responsive single-page layout with a language switcher and mailto-based quote form

## Technologies

- Astro 5
- TypeScript configuration via Astro strict tsconfig
- Custom CSS
- Static output suitable for Cloudflare Pages
